# ESP Home / gk-server

Корень этого репозитория — основная рабочая папка проекта.

Перед изменениями:

1. Прочитать `.agents/project.md` и применимый skill из `.agents/skills/`.
2. Проверить `git status --short`.
3. Использовать `docs/project/` как актуальную техническую документацию.
4. Для работы с действующим экземпляром прочитать `.local/remote-host.md`.

Не считать старые инструкции в `docs/system/` полностью актуальными без сверки с кодом.
Не коммитить `vendor/`, SQLite-базу, локальные секреты и сгенерированные web-assets.

## Публичные и локальные данные

Репозиторий публичный.

## Агентные материалы и навыки

Все специфичные для этого проекта роли агентов, skills, шаблоны и скрипты
хранятся в отслеживаемой `.agents/`. Не создавать дубли таких материалов в
глобальных каталогах Codex: клон репозитория должен содержать всё необходимое
для работы с проектом. Общесистемные skills Codex допустимы только как внешние
инструменты, но не как место хранения проектных правил.

Перед делегированием задачи агенту выбрать роль из `.agents/roles/`, передать
ей только конкретную ограниченную задачу и не поручать двум агентам параллельно
изменять одну миграцию, layout, asset-пакет или конфигурацию развёртывания.

- Локальные адреса, пользователи, пути действующего сервера, SSH-конфигурацию,
  отпечатки ключей, состояние рабочей машины и другие инфраструктурные детали
  хранить только в `.local/` в корне этой рабочей области.
- Пароли, приватные ключи и токены не сохранять ни в рабочей области, ни в Git.
- В репозиторий добавлять только сведения, полезные другим пользователям проекта:
  архитектуру, общие инструкции, шаблоны конфигурации и требования без локальных
  значений.
- Перед добавлением документации или конфигурации проверять, не
  раскрывает ли она частную сеть или конкретное окружение владельца.
