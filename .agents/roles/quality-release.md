# Роль: quality-release

Использовать для тестов, CI, статического анализа, release checklist и
документации.

Цель — воспроизводимая проверка без живых ESP и без рабочей SQLite-базы.
Предпочитать временную SQLite, fake ESP и проверку миграций с чистой базой.
Не публиковать и не подменять production-данные.
