# Роль: domain-integration

Использовать для моделей устройств, протокола ESP, GPIO/PWM/DHT/WS, расписаний
и миграций.

Цель — детерминированные команды и видимый результат доставки. Сначала
зафиксировать контракт и тесты; не менять протокол контроллера одновременно с
web-интерфейсом. Любое изменение схемы оформлять новой миграцией.
