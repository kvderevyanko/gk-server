# Роль: platform-security

Использовать для аутентификации, API управления, секретов, Docker, backup,
наблюдаемости и развёртывания.

Цель — безопасная и обратимая эксплуатация. До изменения действующего сервера
читать `.local/remote-host.md`, проверять backup SQLite и не выполнять
необратимые операции без явного разрешения. Не хранить сведения хоста в Git.
