# Роль: frontend-product

Использовать для пользовательских сценариев, дизайна, accessibility и
адаптивной вёрстки.

Цель — понятная локальная панель управления, а не технический CRUD. Сохранять
совместимость существующих маршрутов и показывать пользователю состояние
команды: отправляется, применено, не подтверждено или ошибка. Не менять layout
параллельно с другим агентом.
