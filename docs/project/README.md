# Документация проекта ESP Home / gk-server

Этот каталог описывает фактическое состояние репозитория `gk-server`: серверное приложение на Yii2, локальную базу SQLite и Lua-код для контроллеров ESP8266 с NodeMCU.

## Состав документации

- [Архитектура](architecture.md) — компоненты, модель данных и потоки запросов между браузером, Yii2, SQLite и ESP.
- [Разработка](development.md) — зависимости, локальная установка, запуск и доступные проверки.
- [Эксплуатация](operations.md) — миграции, cron, подготовка NodeMCU и диагностика.
- [Риски](risks.md) — подтверждённые технические риски и предлагаемый порядок их устранения.

## Назначение проекта

Приложение хранит конфигурацию домашних устройств и периферии, показывает веб-интерфейс управления и отправляет HTTP-запросы на ESP8266. В репозитории реализованы:

- цифровые выходы GPIO;
- PWM;
- датчики температуры и влажности DHT;
- адресные светодиоды WS2812;
- заготовки для SSD1306 и gamepad;
- расписания для GPIO и отдельная периодическая логика моторных GPIO.

Серверная часть не является прошивкой ESP. Она работает отдельно и обращается к HTTP-серверу, реализованному в `nodemcu/code/`.

## Основные точки входа

| Назначение | Файл |
|---|---|
| Веб-приложение | `web/index.php` |
| Консольное приложение | `yii`, `config/console.php` |
| Веб-конфигурация | `config/web.php` |
| Подключение к БД | `config/db.php` |
| Управление устройствами | `controllers/DeviceController.php` |
| HTTP-клиент для ESP | `components/EspRequest/` |
| Периферийные модули | `modules/gpio`, `modules/pwm`, `modules/dht`, `modules/ws` |
| Периодические команды | `commands/CommandController.php`, `commands/DhtController.php`, `commands/MotorController.php` |
| Lua-код ESP | `nodemcu/code/` |
| Миграции | `migrations/` |

## Границы достоверности

Документация составлена по исходному коду и файлам репозитория. В репозитории отсутствуют `composer.lock`, `vendor/` и готовая `db/sqlite.db`, поэтому установка зависимостей, полный запуск приложения и автоматические тесты не были воспроизведены в текущем состоянии рабочей копии.
