# Разработка

## Требования из репозитория

`composer.json` требует:

- PHP `^7.4 || ^8.1`;
- Yii2 `~2.0.14`;
- расширения и пакеты для SQLite, HTTP-клиента, Bootstrap, SwiftMailer и Chart.js;
- Codeception 4 и модули тестирования в `require-dev`.

Рабочий экземпляр проверен на PHP 8.1. Поддержка PHP 7.4 сохранена для
совместимости, но эта ветка PHP больше не получает исправления безопасности и
не рекомендуется для нового production-развёртывания.

## Состояние рабочей копии

На момент составления документации отсутствуют:

- каталог `vendor/`;
- файл `db/sqlite.db`.

Следствия:

- приложение не запустится до установки Composer-зависимостей;
- `composer install` использует зафиксированные версии из `composer.lock`;
- совместимость зависимостей с целевой версией PHP должна проверяться в
  подготовленном окружении;
- миграции нельзя выполнить до появления `vendor/`.

## Подготовка

Из корня `gk-server`:

```bash
composer install
php yii app/start
php yii migrate
```

Это команды, соответствующие текущей структуре проекта, но в исходном состоянии репозитория их успешное выполнение не подтверждено.

Особенности `app/start`:

- выставляет `0775` для `runtime`, `web/assets` и `db`;
- создаёт `db/sqlite.db`, если файла нет;
- выставляет файлу БД `0664`;
- напоминает назначить владельца/группу веб-процесса;
- отсылает к актуальной документации cron.

Запись должна быть доступна только владельцу и группе веб-процесса. Для
совместной работы пользователя развёртывания и PHP удобно использовать общую
группу и setgid-бит на writable-каталогах.

## Запуск веб-приложения

Document root должен указывать на `gk-server/web`. Для быстрого локального запуска после установки зависимостей можно использовать встроенный сервер PHP:

```bash
php yii serve --port=8080
```

Либо настроить Apache/Nginx так, чтобы несуществующие файлы перенаправлялись в `web/index.php`. Pretty URL включены, `showScriptName` выключен.

SQLite-файл и каталоги `runtime`, `web/assets` должны быть доступны на запись процессу PHP.

## Конфигурация

Точки входа web и console по умолчанию запускаются с `YII_ENV=prod` и
`YII_DEBUG=false`. Для локальной разработки dev-режим включается явно:

```bash
export COOKIE_VALIDATION_KEY="$(php -r 'echo bin2hex(random_bytes(32));')"
YII_ENV=dev YII_DEBUG=1 php yii
```

`COOKIE_VALIDATION_KEY` обязателен и не хранится в Git. Его задают в окружении
веб-сервера и консольных процессов либо в игнорируемом `.env` (если окружение
развёртывания загружает такой файл). Для каждого окружения следует создать своё
случайное значение; шаблон приведён в `.env.example`.

Остальная конфигурация пока не полностью вынесена в переменные окружения:

- DSN задан непосредственно в `config/db.php`;
- production и development используют общую конфигурацию приложения.

При локальной работе не следует коммитить реальные сетевые адреса устройств, секреты Wi-Fi или рабочую БД. `db/.gitignore` исключает содержимое каталога БД.

## Проверки

### Синтаксис PHP

Проверка не требует `vendor/`:

```bash
find . -name '*.php' -not -path './vendor/*' -print0 \
  | xargs -0 -n1 php -l
```

Она проверяет только синтаксис и не доказывает совместимость с версией Yii2 или корректность выполнения.

### Codeception

После установки dev-зависимостей:

```bash
vendor/bin/codecept run
```

Фактическое покрытие минимально:

- есть один acceptance-тест `tests/acceptance/FirstCest.php`;
- он открывает `/` по адресу `http://gk-server/`;
- проверяется только наличие текста `Главная`;
- содержательных unit- и functional-тестов нет.

Перед acceptance-тестом нужен доступный виртуальный хост `gk-server` либо изменение локальной конфигурации `tests/acceptance.suite.yml`.

### Проверка миграций

После установки зависимостей и создания БД:

```bash
php yii migrate/history
php yii migrate
```

Для проверки с чистой БД следует использовать отдельный временный SQLite-файл через отдельную конфигурацию. Репозиторий содержит `config/test_db.php`, но штатная консольная конфигурация использует `config/db.php`.

## Ограничения локальной проверки

Без реального ESP можно проверить веб-CRUD и работу SQLite, но действия GPIO/PWM/DHT/WS будут обращаться к адресу из `device.host` и ждать до двух секунд. Встроенного эмулятора ESP или мок-транспорта в репозитории нет.
