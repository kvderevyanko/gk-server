# Интерфейс и пользовательские сценарии

## Назначение

Интерфейс — локальная панель управления домом. Обычный пользователь должен
понимать состояние устройства и результат команды без знания GPIO-пинов,
HTTP-endpoint'ов или структуры SQLite.

## Структура

| Раздел | Задача пользователя | Содержимое |
|---|---|---|
| Обзор | Быстро управлять домом | Избранные устройства и карточки управления |
| Устройство | Управлять одним ESP | Переключатели, датчики и периферия выбранного устройства |
| Настройки | Настраивать систему | Технические CRUD-экраны устройств, пинов, PWM, WS и DHT |

Основной layout использует адаптивную боковую навигацию. На малом экране она
открывается кнопкой меню; в разметке есть skip-link для перехода к содержимому.

## Карточка GPIO

Карточка показывает устройство, имя переключателя, номер пина и выбранное
состояние. Toggle остаётся нативным checkbox, поэтому доступен с клавиатуры и
экранному диктору. Зона касания не меньше 44 px.

После действия пользователь видит один из статусов:

| Статус | Значение |
|---|---|
| `Отправляем…` | Браузер ожидает ответ Yii2 |
| `Включено` / `Выключено` | ESP подтвердил команду |
| `Не подтверждено` | Значение сохранено как желаемое, но доставка на ESP не подтверждена |

Интерфейс не повторяет GPIO-команду автоматически: повтор может быть опасен
для реле и моторов. Оператор принимает решение о следующей попытке сам.

## Доступность и визуальные правила

- CSS-токены задают поверхность, текст, границы, акцент и статусы;
- поддерживается системная светлая и тёмная тема;
- `prefers-reduced-motion` отключает декоративные анимации;
- фокус отображается явно, динамический статус передаётся через `aria-live`;
- имена устройств и настроек экранируются перед выводом.

## Границы текущей реализации

Новая оболочка и карточки реализованы для GPIO. DHT, PWM и WS пока используют
исторические виджеты и должны переноситься по одному сценарию за раз, сохраняя
понятные состояния доставки. Аутентификация и роли ещё не реализованы: UI не
следует считать защитой доступа к физическим устройствам.
